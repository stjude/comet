# Contributing

This repository holds several independently maintained components (`WSI_analysis/`, `MELD/`,
`MeQTrack_app/`). In general: open a GitHub issue for bugs/questions, and keep pull requests
small and focused.

`WSI_analysis/` and `MELD/` each have their own `CONTRIBUTING.md` with specifics on running
things locally, testing, and code style — **go to that folder's file for details** before
opening a PR against it. For any other component (e.g. `MeQTrack_app/`) that doesn't yet have
its own guide, this root-level file applies.
