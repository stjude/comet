# Code of Conduct

All components in this repository follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
Concerns can be reported to GitHubAdministrators@stjude.org.

`WSI_analysis/` and `MELD/` each have their own `CODE_OF_CONDUCT.md` with the full text and
the contact address for reporting concerns — go there first if you're working in one of those
folders. This root-level file is the fallback for any other component (e.g. `MeQTrack_app/`)
that doesn't yet have its own copy.
