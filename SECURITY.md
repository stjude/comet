# Security Policy

Please do **not** open a public GitHub issue for a security vulnerability. Instead, use
GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
feature on this repository, or contact the maintainers directly.

`WSI_analysis/` and `MELD/` each have their own `SECURITY.md` with component-specific scope
and response details — go to that folder's file first if you're reporting an issue in one of
those. For any other component (e.g. `MeQTrack_app/`) that doesn't yet have its own policy,
this root-level file applies: we aim to acknowledge reports within 5 business days.
